Proyecto de chatbot empresarial en noide.js que funciona como una API cliente realizando peticiones al motor de OpenAI (GPT-4.5 mini) para generar respuestas inteligentes.
Diseñado para atención y soporte de una empresa de insumos médicos, con conversación dinámica en lenguaje natural y flujo de diálogo funcional.

Autor: Martin Cajiao
